# Ready When Needed: Build Your 90-Day Home Reserve

Free printable 90-day home supply checklist with staged goals (3/14/30/90 days), water treatment, fuel estimate, and two-bucket toilet setup.

## What's included

| File | Description | Size |
|---|---|---|
| `90-day-supply-list.pdf` | The checklist. US Letter, 7 pages, black and white. | 23 KB |
| `build.py` | Source file. Edit text here, run to rebuild the PDF. | 24 KB |

## Notes

- Quantities are planning estimates, not a verified meal plan. Check calories, serving sizes, and dietary needs for your household.
- Sources: CDC (cdc.gov/water-emergency, cdc.gov/carbon-monoxide), EPA (epa.gov/ground-water-and-drinking-water/emergency-disinfection-drinking-water), FEMA (ready.gov/kit), Oregon State University Extension (extension.oregonstate.edu/catalog/pub/em9334).

## Updating this file

1. Edit the text in `build.py` and bump the version number in it (footer and PDF metadata).
2. Run: `python build.py`
3. Add a Changelog line.
4. Commit to `main` as "90-day-supply-list vX.X".
5. Wait for "pages build and deployment" to show green in Actions.
6. On fancyape.com, update the link's `?v=` number to the new version.
