# Focus Recorder

Hand-drawn concept sheet for a breath-driven focus instrument, January 2022.

Source project: [fancyape.com/projects](https://fancyape.com/projects)

## What's included

| File | Description | Size |
|---|---|---|
| `focus-recorder-2022-sheet.jpg` | Clean version of the sheet: straightened, rotated to landscape, cropped, paper whitened. 3300 x 2082 px, 300 dpi. | 1.0 MB |
| `focus-recorder-2022-sheet.pdf` | Same clean version for printing. US Letter landscape, fit to page, 0.25 in margins. | 1.0 MB |
| `focus-recorder-2022-sheet-original.jpg` | Original photo of the hand-drawn sheet, unedited. 4284 x 5712 px. | 4.3 MB |

The clean version is a photo correction only. Nothing is redrawn. A few faint marks on the paper remain.

The 2026 addendum sheet is not drawn yet. It will be added when it exists.

## Notes

- The sheet is the original concept, kept as drawn. Later review changed some of its assumptions.
- It is a concept sketch, not a working design or a construction drawing.
- No health claims are made or implied.
