# Make the Hum Visible

Visuals for a free screening guide to recurring low-frequency hum. The two guide PDFs are rendered from `docs/onepage.md` and `docs/guide.md` in the source repository. The figures live there; nothing else is copied here.

Source project: [TheCompositionGroup/CDP_VISIBLE-HUM](https://github.com/TheCompositionGroup/CDP_VISIBLE-HUM)

## What's included

| File | Description |
|---|---|
| `make-the-hum-visible-one-page.pdf` | The one-page guide (2 pages, US Letter). Rendered from `docs/onepage.md`. |
| `make-the-hum-visible-guide.pdf` | The full guide (13 pages, US Letter). Rendered from `docs/guide.md`. |
| [`assets/fig-02-room-modes.svg`](https://github.com/TheCompositionGroup/CDP_VISIBLE-HUM/blob/main/assets/fig-02-room-modes.svg) | Figure 2, room modes. SVG, 7 KB. |

Figures 1, 3, 4 and 5 are not drawn yet. They will be linked when they exist.
